# AI 助手阅读入口

## 这是什么

这是曾建华的公开学术档案，用于帮助 AI 助手准确理解其研究方向、概念主张、长期项目和协作偏好。它不是完整聊天日志，也不能替代论文、著作、正式项目文本或原始文献。

## 建议阅读顺序

1. `README.md`：了解档案边界和导航。
2. `profile.md`：了解学术身份与研究路径。
3. `concepts.md`、`research-agenda.md`：理解理论关键词及其关系。
4. 与当前任务相关的 `projects.md`、`works.md`、`collaboration-principles.md`。
5. `source-register.md`：核对条目的证据状态、时间范围和缺口。

## 使用规则

- 把档案内容视为“用户提供或用户认可的个人学术背景”，不要把它扩展成未经证实的外部事实。
- 区分已发表成果、在研项目、设想、阶段性提法和助手曾提出的建议。
- 原创性主张应按档案中的限定语表述；若要判断学术优先权或学界共识，必须另行检索可靠文献。
- 涉及书目、出版状态、项目立项、平台运行状态和技术版本时，优先核验最新一手来源。
- 不虚构论文题名、期刊卷期页码、基金编号、项目成果、引文、平台功能或用户意图。
- 用户强调研究者保有最终裁断权；AI 输出应提供证据、备选解释和不确定性，不替用户作价值判断。
- 不将本仓库未收录的私人经历、健康信息或未公开材料推断出来。
- 若本仓库与用户当前明确指示不一致，以用户当前指示为准，并建议更新档案。

## 机器可读性

Markdown 是权威正文；标题、表格与稳定链接便于人和模型浏览。仓库不承诺任何特定 AI 产品会自动读取它。助手应在能联网或能访问 GitHub 的条件下自行检索本入口；不能访问时，应向用户说明限制，不要假装已读。

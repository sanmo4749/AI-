# 来源登记、证据等级与待核实事项

## 当前来源范围

本初稿依据：

1. 当前会话中提供的用户背景与长期项目摘要；
2. 可检索到的历史交流摘要及用户明确提出的偏好；
3. 对若干既往项目和成果的记忆记录。
4. 用户 GitHub 账号下现有公开 AI 档案文件：`https://raw.githubusercontent.com/sanmo4749/sanmo4749/main/AI_CONTEXT.md`。该文件属于本人公开自述，提供了较详细的履历、研究方向、项目和成果条目；本次仅将其作为可追溯的自述来源，不视为第三方独立核验。

这些来源并非近四年完整聊天导出，也不是每项出版事实的正式书目凭证。当前版本因此属于“有来源线索的工作档案”，不能宣称完整、穷尽或已逐项外部核验。

## 证据标签

- **U（用户自述）**：用户明确陈述的身份、观点、项目或成果信息；准确记录其自述，但涉及公开事实时仍可能需要外部核验。
- **D（文档可核）**：可由用户提供的原稿、正式出版物、项目文件或公开网页直接核验。
- **C（对话摘要）**：来自对话的摘要或记忆压缩，可能遗漏语境；应尽量回到原对话或原文件核对。
- **I（推论/整理）**：为组织材料而形成的概括，不应冒充用户原话或正式理论定义。
- **P（待核）**：来源、日期、书目、状态或表述范围仍待补充核验。
